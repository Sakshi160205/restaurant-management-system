# 🍽️ Restaurant Management System

A full-stack **Restaurant Management System** developed using the **MERN stack** — MongoDB, Express.js, React.js, and Node.js.

The system provides functionality for managing restaurant menus, users, and orders through a responsive React frontend and RESTful backend APIs.

---

## 📌 About the Project

The Restaurant Management System is designed to simplify restaurant operations by providing a centralized platform for managing:

- Menu items
- Users
- Customer orders
- Restaurant data
- CRUD operations

The application follows a full-stack architecture where the React frontend communicates with the Node.js and Express.js backend, while MongoDB is used for data storage.

---

## 🚀 Features

### 👤 User Management
- Add, view, update, and delete users
- Manage user information
- User data stored in MongoDB

### 🍔 Menu Management
- Add restaurant menu items
- View available menu items
- Update menu information
- Delete menu items

### 🛒 Order Management
- Create and manage customer orders
- View order information
- Update and delete orders
- Store order data in MongoDB

### 🔄 CRUD Operations
The application implements complete CRUD operations:

- **Create** – Add new records
- **Read** – Retrieve existing records
- **Update** – Modify records
- **Delete** – Remove records

### 🔗 RESTful APIs
Backend APIs are implemented using **Node.js and Express.js** to communicate between the frontend and database.
